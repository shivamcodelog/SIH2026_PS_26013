# Sample Geospatial Datasets

This directory contains synthetic benchmark datasets used to demonstrate the intelligent harmonization and conflict detection pipeline:

1. `cadastral.geojson` — Cadastral/parcel boundaries with parcel IDs, legal landholder names, and registered deed areas.
2. `municipal.geojson` — Municipal property tax records representing urban plots with property IDs, local holder names, and tax-assessed areas.
3. `buildings.geojson` — High-resolution drone-derived building footprints with structural IDs and spatial outlines.

> **Note**: All sample datasets are strictly synthetic and generated for demonstration, testing, and algorithmic validation.
